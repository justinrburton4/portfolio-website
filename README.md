# Justin Burton Portfolio

A static personal portfolio built around Justin Burton's work in physical product design, embedded systems, and independent software products, with design research as a supporting discipline.

## Run locally

```powershell
npm start
```

The default address is `http://127.0.0.1:4173`. If that port is occupied, pass another port directly:

```powershell
node server.mjs 4321
```

## Verify

```powershell
npm test
npm run build
```

The production-ready static files are written to `dist/`.

## Content sources

- `assets/documents/Justin-Burton-Resume.pdf`
- `assets/documents/Justin-Burton-Design-Portfolio.pdf`
- Justin's public LinkedIn profile
- Local project repositories under `C:\Users\justi\Programming`
- The public Synaptech project portfolio

The cover letters supplied for the project informed tone only. Their job-specific language is not presented as portfolio evidence.
